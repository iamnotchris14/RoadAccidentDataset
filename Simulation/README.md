🚦 Traffic Accident Risk Dashboard

A Streamlit Web Application for Driver, Government & Emergency Response Insights

This project is an interactive dashboard built using Python, Streamlit, Pandas, Plotly, and Scikit-Learn.
It allows users to explore traffic accident patterns and predict accident severity using machine-learning models.

📌 Features

1️⃣ Multi-Role Home Pages

Each role sees a custom introduction explaining:

- Their responsibility

- Why the insights matter

- Real-world accident facts and visuals

2️⃣ Analysis Page (Interactive EDA)

Each role receives tailored analytics:

Driver (3 charts)

- Accident distribution by time of day (Donut)

- Injury vs fatality (Pictogram)

- Accident Cause Distribution (Treemap)

Government (3 charts)

- Road Distribution of Accidents (Waffle)

- Accident Cases in Urban vs Rural Area by Country (Group Bar)

- Fatalities over the Years by Country

Emergency Responders (2 charts)

- Emergency Response Time : Urban vs Rural (Dumbbell)

- Average Accident Severity by Country (Choropleth)


3️⃣ Prediction Page

- Driver              : Accident Severity Prediction

- Government          : Economic Loss Prediction

- Emergency Responder : Emergency Response Time Prediction

All of the prediction are relevant with each of the roles.

🎯 Purpose of This Project

Understand real-world accident risk patterns

Improve safety through data-driven visualisations

Assist emergency responders & government planners

Demonstrate proficiency in Python data science, visualisation, and ML deployment
