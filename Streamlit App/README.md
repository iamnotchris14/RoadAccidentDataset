Global Road Accidents Dataset

About Dataset:

This dataset provides a road accident data from around the world, containing 1,32,000 rows and 30 diverse features. It captures various factors such as accident severity, weather conditions, vehicle involvement, driver characteristics, and geographic regions. Designed for beginners, intermediates, and advanced users, this dataset is perfect for exploratory data analysis (EDA), feature engineering, and training machine learning models to predict accident severity, fatalities, and other impactful outcomes.
